One Emoji, One Smile: the program writes exactly one emoji — 🤗 Hugging Face — to `/output/entry.txt`. A warm, universal, friendly hug offered to a stranger: instantly readable, chosen rather than the default smiley, with no intimacy, sarcasm or flirtation. A single code point, no variation selector, no ZWJ sequence, no trailing newline.

## Run it

```sh
node main.ts
```
